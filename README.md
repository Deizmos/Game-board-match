# 🎲 GameBoardMatch

Мобильное приложение для знакомств, специализированное на настольных играх.

## 🚀 Быстрый старт

### Установка зависимостей
```bash
npm install
```

### Запуск приложения
```bash
# Запуск в режиме разработки
npm start

# Запуск на iOS
npm run ios

# Запуск на Android
npm run android

# Запуск в браузере
npm run web
```

## 📱 Функционал

### ✅ Реализовано
- **Авторизация**: Регистрация и вход в систему
- **Онбординг**: Настройка предпочтений в играх после регистрации
- **Поиск игроков**: Карточки пользователей с информацией о предпочтениях
- **Система матчинга**: Лайки, пасы и взаимные матчи
- **Чат**: Обмен сообщениями с принятыми матчами
- **Профиль**: Просмотр и редактирование профиля пользователя

### 🔄 В разработке
- Система геолокации и разрешений
- Push-уведомления
- Расширенные фильтры поиска
- Система рейтингов и отзывов

## 🏗️ Архитектура

### Frontend
- **React Native + Expo**: Кроссплатформенная разработка
- **Tamagui**: Современный UI framework
- **Expo Router**: File-based навигация
- **Zustand**: Управление состоянием
- **TypeScript**: Типизация

### Backend (планируется)
- **Supabase**: Backend-as-a-Service
- **PostgreSQL + PostGIS**: База данных с геопространственными функциями
- **Real-time**: WebSocket соединения для чата

## 🔧 Настройка

### Переменные окружения
Создайте файл `.env` в корне проекта:

```env
EXPO_PUBLIC_FIREBASE_API_KEY=your_api_key
EXPO_PUBLIC_FIREBASE_AUTH_DOMAIN=your_auth_domain
EXPO_PUBLIC_FIREBASE_PROJECT_ID=your_project_id
EXPO_PUBLIC_FIREBASE_STORAGE_BUCKET=your_storage_bucket
EXPO_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=your_sender_id
EXPO_PUBLIC_FIREBASE_APP_ID=your_app_id
```

## 📱 Экраны приложения

### 1. Авторизация
- **Главная**: Приветствие и выбор действия
- **Регистрация**: Создание аккаунта с базовой информацией
- **Вход**: Авторизация существующих пользователей

### 2. Онбординг
- **Шаг 1**: Выбор предпочтений в играх (категории, уровень навыков, стиль игры)
- **Шаг 2**: Написание биографии
- **Шаг 3**: Настройка параметров поиска (радиус, возрастной диапазон)
- **Шаг 4**: Подтверждение настроек

### 3. Основное приложение
- **Поиск**: Карточки игроков с возможностью лайка/паса
- **Матчи**: Список взаимных лайков и их статусы
- **Сообщения**: Чат с принятыми матчами
- **Профиль**: Просмотр и редактирование профиля

## 🎯 Особенности

### Система матчинга
- **Лайк**: Выражение интереса к игроку
- **Пас**: Пропуск игрока
- **Матч**: Взаимный лайк открывает чат
- **Совместимость**: Расчет на основе общих предпочтений в играх

### Геолокация
- Поиск игроков в заданном радиусе
- Отображение расстояния до игрока
- Настройка радиуса поиска

### Безопасность
- Аутентификация через Firebase
- Защита персональных данных
- Настройки приватности
