# 📋 Информация о проекте GameBoardMatch

## 🎯 Концепция

**GameBoardMatch** - это мобильное приложение для знакомств, специализированное на настольных играх. В отличие от обычных приложений знакомств, здесь люди ищут друг друга по общим интересам в настольных играх и географическому местоположению.

## 🏗️ Архитектура

### Frontend (React Native + Expo)
- **UI Framework**: Tamagui для современного дизайна
- **Навигация**: Expo Router с file-based routing
- **Состояние**: Zustand для глобального состояния
- **Серверные запросы**: TanStack Query для кеширования и синхронизации
- **Формы**: React Hook Form + Zod для валидации
- **Типизация**: TypeScript для безопасности типов

### Backend (Supabase)
- **База данных**: PostgreSQL с PostGIS для геопространственных запросов
- **Аутентификация**: Supabase Auth
- **Real-time**: Supabase Realtime для чата
- **Storage**: Supabase Storage для изображений
- **API**: Автогенерируемые API из схемы БД

### Геолокация и карты
- **Геолокация**: Expo Location
- **Карты**: React Native Maps с Google Maps
- **Поиск по радиусу**: PostGIS функции для эффективного поиска

## 💬 Система матчинга

### Статусы матчей
- **pending**: Ожидает ответа
- **accepted**: Принят обеими сторонами
- **declined**: Отклонен
- **expired**: Истек (время ожидания)

### Процесс матчинга
1. Пользователь A лайкает пользователя B
2. Создается матч со статусом "pending"
3. Пользователь B получает уведомление
4. Пользователь B принимает или отклоняет
5. При принятии открывается чат

- **find_users_in_radius()**: Поиск пользователей в радиусе
- **PostGIS**: Геопространственные запросы
- **RLS**: Row Level Security для безопасности

## 🔐 Безопасность

### Аутентификация
- Supabase Auth с JWT токенами

### Приватность
