# 🚀 Быстрый старт GameBoardMatch

## Шаг 1: Настройка Supabase

1. **Создайте проект в Supabase:**
   - Перейдите на [supabase.com](https://supabase.com)
   - Создайте новый проект
   - Дождитесь завершения инициализации

2. **Настройте базу данных:**
   - Откройте SQL Editor в Supabase
   - Скопируйте и выполните содержимое файла `database/schema.sql`
   - Убедитесь, что все таблицы созданы успешно

3. **Получите ключи API:**
   - В настройках проекта найдите "API"
   - Скопируйте URL и anon key

## Шаг 2: Настройка приложения

1. **Скопируйте переменные окружения:**
```bash
cp env.example .env
```

2. **Заполните .env файл:**
```
EXPO_PUBLIC_SUPABASE_URL=your_supabase_url_here
EXPO_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key_here
```

## Шаг 3: Запуск

1. **Установите зависимости:**
```bash
npm install
```

2. **Запустите приложение:**
```bash
npm start
```

3. **Выберите платформу:**
   - Нажмите `i` для iOS Simulator
   - Нажмите `a` для Android Emulator
   - Нажмите `w` для веб-браузера

## Шаг 4: Тестирование

1. **Зарегистрируйтесь** с тестовым email
2. **Настройте предпочтения** в играх
3. **Разрешите геолокацию** для поиска игроков
4. **Создайте несколько тестовых пользователей** для проверки матчинга

## 🔧 Возможные проблемы

### Ошибка геолокации
- Убедитесь, что разрешения предоставлены
- Для iOS: проверьте настройки в Simulator > Device > Location

### Ошибки Supabase
- Проверьте правильность URL и ключей
- Убедитесь, что RLS политики настроены
- Проверьте логи в Supabase Dashboard

### Проблемы с зависимостями
```bash
# Очистите кеш и переустановите
rm -rf node_modules package-lock.json
npm install
```

## 📱 Тестирование на устройстве

2. **Запустите `npm start`**
3. **Отсканируйте QR-код** в Expo Go
4. **Разрешите геолокацию** на устройстве
